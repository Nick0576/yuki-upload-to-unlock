# Yuki emotion images

Drop the 23 emotion PNGs in this folder (`assets/emotions/`).

Rules the app expects:

- One PNG per emotion, named with the emotion in lowercase, e.g. `happy.png`, `blush.png`, `sad.png`.
- Transparent background, Yuki cut out (no scene behind her).
- Square-ish and portrait-friendly: 512x1024 or 1024x1024 works best.
- Keep each file under ~400 KB so the app stays small.

The app loads whatever is in here at runtime and falls back to the emoji
badge (placed near her hair, upper-right) for any emotion that has no image.
